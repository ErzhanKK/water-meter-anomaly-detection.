# Water Meter Anomaly Detection

Анализ суточного расхода воды и поиск аномалий по накопительным показаниям приборов.

## Данные

Исходные CSV из тестового задания поместите в папку `data/`:
- `pokazaniya.csv`
- `sobytiya.csv`
- `pribory.csv` (метаданные, пока не используются скриптом)

Исходные данные исключены из Git через `.gitignore`: перед публичной публикацией нужно проверить разрешение работодателя на распространение данных.

## Запуск

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python analyze.py
# Linux/macOS: .venv/bin/pip install -r requirements.txt && .venv/bin/python analyze.py
```

Результаты появятся в `results/`: `summary.csv`, `daily_calculated.csv`, `leak_runs.csv`, `zero_runs.csv`.

## Метод

Для каждого `anon_id` сортируем записи по дате. Суточный расход равен разности накопительных показаний **только если** между записями ровно 1 день. Пропуски дат не интерполируются.

1. **Отрицательный расход:** `daily < 0`.
2. **Всплеск:** `daily > 2 м³` и `daily >= 5 × baseline`, где baseline = медиана положительных суточных расходов прибора, минимум 10 наблюдений и baseline >= 0.01 м³.
3. **Экстремальный расход:** `daily > 100 м³`. Это эвристика, не доказательство физической невозможности без технических характеристик.
4. **Возможная утечка:** не менее 14 последовательных дней с `0.01 < daily <= 10` и `paketov_za_sutki > 0`.
5. **Длительный ноль:** не менее 14 последовательных дней с `abs(daily) <= 0.001` и `paketov_za_sutki > 0`.
6. **Ступенька:** медианы первой и второй календарных половин различаются минимум в 3 раза, в каждой >=20 наблюдений, обе медианы >=0.02 м³; для расчёта используется диапазон `0 <= daily <= 10`.
7. **Магнит:** сравнение частот отрицательного расхода и всплесков в даты с событием «магнит» и без него. Повторы событий за один день объединяются.

## Ограничения

- Суточные данные не позволяют доказать ночной непрерывный поток, а значит и утечку.
- Порог 100 м³ не учитывает паспортную пропускную способность прибора.
- «Ступенька» по половинам периода не определяет точную точку изменения.
- Совпадение магнитного события с аномалией в тот же день не доказывает причинность и не исключает отложенный эффект.
- Данные не следует считать реальными персональными показаниями без подтверждения их происхождения.
