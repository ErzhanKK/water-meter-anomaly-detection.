# Анализ показаний водосчётчиков

Тестовое задание: расчёт суточного потребления воды и поиск аномалий в показаниях приборов.

## Запуск

Python 3.10+; библиотеки `pandas`, `numpy`.

```bash
pip install -r requirements.txt
python analyze.py
```

Исходные файлы `pokazaniya.csv`, `sobytiya.csv`, `pribory.csv` должны находиться в папке `data/`. Скрипт записывает таблицы в `results/`.

## Проверки

Суточный расход рассчитывается как разница соседних накопительных показаний **только для последовательных дат**. Интервалы с пропусками дней исключаются.

| Проверка | Критерий | Приборов |
|---|---|---:|
| Отрицательный расход | Изменение показаний < 0 | 294 |
| Всплески | > 2 м³/сутки и ≥ 5 медианных расходов прибора | 126 |
| Экстремальные значения | > 100 м³/сутки | 55 |
| Возможная утечка | 14+ дней подряд с расходом > 0,01 и ≤ 10 м³/сутки | 1 470 |
| Длительный ноль | 14+ дней без изменения показаний при наличии пакетов | 1 117 |
| Изменение уровня («ступенька») | Медианы двух половин периода различаются в ≥ 3 раза | 48 |

Также сопоставляются аномалии с событиями «магнит». Выраженной связи в пределах одного дня не обнаружено.

Дополнительно обнаружены пропуски дат, а также приборы с сочетанием отрицательных и экстремальных положительных изменений.

## Файлы результатов

- `summary.csv` — количество приборов и примеры ID по типам аномалий.
- `daily_calculated.csv` — расчёт суточного расхода.
- `leak_runs.csv` — периоды непрерывного положительного расхода.
- `zero_runs.csv` — периоды нулевого расхода.

Пороговые значения являются аналитическими критериями для поиска подозрительных случаев. Они не доказывают неисправность или утечку без дополнительной проверки.
